##### Version 26.0.26284.0 _(available from October 12, 2026)_
- Added the **Automatic Default Dimensions** feature.
  - _Makes possible the automatic creation of Default Dimensions for tables such as Item, Customer, Fixed Asset, Employee, etc. when a new record is created._
- It is now possible to add **Related Dimensions** to Global Dimension Values not only from the **Dimension Values** page but also from the **Dimensions** page.
  - _This also provides a better overview of all Related Dimension setups linked to the Global Dimension._
- The **Related Dimensions** page now also displays the **Base Dimension Value Name**.
  - _The Dimension Value Name can also be edited directly from this page._
- On the **Fixed Asset List**, the **Book Value** now changes according to the **FA Posting Date Filter** setting. 

##### Version 23.0.26041.0 _(available from February 11, 2026)_
- Fixed an issue where **Global Dimension 1** sent through a web service was removed from an entry due to the **Related Dimensions** functionality.
- Non-functional technical improvements.  

##### Version 23.0.26038.0 _(available from February 7, 2026)_
- Usability improvements for the **Fringe Benefit** functionality.
  - _Automatic removal of Fringe Benefit tax lines when the Fringe Benefit Account is modified or deleted._
